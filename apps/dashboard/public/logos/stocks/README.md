# Logos das ações

SVGs 56×56 (fundo quadrado com a cor da marca; o app recorta em círculo),
um por símbolo do Yahoo Finance (`BRK-B.svg`, não `BRK.B.svg`).

Fonte: https://github.com/ShaadyEmad/ticker-logos (pasta `US Market/SVG`,
originalmente da Finnhub). Os logos são marcas das empresas e são usados só
para identificar o ativo. Para adicionar uma empresa: copie o SVG com o nome
do símbolo e inclua o símbolo em `STOCK_LOGOS`
(`components/pages/trading/symbol-icon.tsx`).
